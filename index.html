ADM • Banco de Dados EPI-MISU




EPI-MISU V1.0: o Banco inicial foi criado a partir da planilha LISTA BANCO DE DADOS.xlsx. O campo URL da API começa vazio para não utilizar o Worker da loja de livros. Em modo local, dados e vendas ficam neste navegador; ao conectar um novo Worker/D1 EPI-MISU, o controle passa a ser compartilhado.
Modo local de V1.0: preços, estoque e Controle de Vendas funcionam no navegador para testes. Para operação pública com vários clientes, conecte um Worker/D1 exclusivo EPI-MISU no ADM.
